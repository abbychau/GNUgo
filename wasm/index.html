About this page

  

    
GNU Go is the Go program of the GNU project, free software under the GPL. Its last
    official release, 3.8, came out in 2009. This page runs a modernized version of it:
    the whole engine, pattern databases included, is compiled to WebAssembly (about 1 MB
    to download) and plays in a background thread of your browser, so the page stays
    responsive while it thinks.

    
Click an intersection to play. Hint suggests three good moves
    for you, Estimate gives the current score, and Score
    ends the game and shows dead stones and territory. Games can be saved and loaded as SGF
    files, and an unfinished game is restored when you return.

  


  
How strong is it?

  
GNU Go chooses its method by board size. On small boards it uses Monte Carlo tree
  search: it plays thousands of quick random games from the current position and keeps
  statistics on which moves win, helped by RAVE, which shares what each game teaches about a
  move across the whole search. On larger boards it uses GNU Go's classic engine, built
  from hand-written Go knowledge and tactical reading.

Level (0 to 10) trades strength for speed; on 9×9 each level adds 1,000
  simulations per move. Time per move lowers the level automatically when
  moves take too long, and Move now stops a long search. For the details and
  the match results, see what's
  different from GNU Go 3.8, or the article on
  MCTS, RAVE and AlphaGo's networks (in Chinese).


  
Use it in your own page

  
The engine comes with a small JavaScript API that runs it in a Web Worker and answers
  with promises. Download gnugo-wasm.zip from the
  latest release, or install
  @abbychau/gnugo-wasm from GitHub Packages,
  and serve the files over HTTP:


import { GnuGo } from "./gnugo.js";

const go = await GnuGo.create();
await go.boardsize(9);
await go.play("black", "E5");
const reply = await go.genmove("white");   // e.g. "C4"
const text = await go.command("estimate_score");   // any GTP command

  
The API
  reference covers time limits, cancelling a search and SGF. For desktop use, the release
  also has programs for Windows, Linux and macOS that work with any GTP client.
